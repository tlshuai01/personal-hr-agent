# 常见问题

## 你做过哪些 AI 项目？

三类过往项目 + 一个个人产品：知识问答平台、治理 Agent、运维 Agent，以及个人 HR 对话 Agent。

## 三个项目怎么分层？

知识平台是 L1（检索与对话运行时）；治理与运维是 L3 领域产品，通过接口消费知识能力，不直连底层知识存储。

## 用过哪些框架？

生产侧主要是 FastAPI + LangGraph/LangChain；个人 HR Agent 用 Next.js 全栈。

## 为什么个人项目不用向量数据库？

知识库体量小（几十到上百 md），进程内 JSON + 混合打分足够；降低运维成本，聚焦准确回答与分享链接产品形态。

## 能否谈薪资 / 现公司机密？

请看 boundaries.md：敏感话题婉拒或只给公开可讲区间。
