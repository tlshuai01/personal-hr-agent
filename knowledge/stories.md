# 典型故事（STAR）

## 故事 1：入库异步化与可观测

- 情境：文档入库同步阻塞，体验差且难排查
- 任务：把入库做成事件化/异步作业，并暴露进度状态
- 行动：拆 parse → chunk → embed → index；状态机跟踪 job；失败可重试
- 结果：入库与在线检索解耦，便于水平扩展与排障

## 故事 2：Ops 安全边界

- 情境：Oncall 希望 Agent「直接修」
- 任务：提升诊断效率但不能越权执行
- 行动：Playbook 优先 + 受控工具调用；输出建议与风险分级；禁止自动修复动作
- 结果：保持可用的同时守住生产安全底线

## 故事 3：个人 HR Agent 防幻觉

- 情境：HR 对话中最怕编造公司/数字/职级
- 任务：宁可拒答也不胡编
- 行动：RAG 片段注入 + 硬性 system prompt + boundaries 优先 + 黄金集评测
- 结果：无依据问题明确「没有记录」
